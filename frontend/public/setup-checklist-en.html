Finance Manager

Setup Checklist — English

Print: Ctrl/Cmd + P → Save as PDF
Minimal Configuration
  • Windows 10/11 64‑bit
  • RAM: 4GB (8GB recommended)
  • Disk: 2GB free
  • Ports open: 8000 (API), 5173 (Frontend)
  • Browser: Chrome/Edge latest
Required Apps
  • Node.js LTS (18/20) with npm
  • Python 3.10+ with pip
  • Git
  • Visual Studio Code
  • Optional: Postman/Bruno
Backend Setup
  • python -m venv .venv
  • Activate venv → install packages
  • pip install -r requirements.txt
  • Run API:
    python -m uvicorn main:app --reload --port 8000
  • Optional .env keys:
    TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_SMS_FROM, TWILIO_WHATSAPP_FROM, RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET, RAZORPAY_WEBHOOK_SECRET
Frontend Setup
  • npm install
  • npm run dev
  • Theme & settings persist in localStorage
  • UI: http://localhost:5173
Networking & OS
  • Windows Firewall: allow inbound 8000, 5173
  • API: http://localhost:8000/settings
  • UI: http://localhost:5173
Optional Tools
  • GitHub Desktop
  • nvs (Node Version Switcher)
  • Image tools (Paint/Photos) — logo upload

Finance Manager

அமைப்பு சரிபார்ப்புப் பட்டியல் — Tamil

Print: Ctrl/Cmd + P → Save as PDF
குறைந்தபட்ச அமைப்பு (Minimal Configuration)
  • Windows 10/11 64‑bit
  • RAM: 4GB (உத்தமம் 8GB)
  • Disk: 2GB free
  • Ports: 8000 (API), 5173 (Frontend)
  • Browser: Chrome/Edge latest
தேவையான மென்பொருட்கள் (Required Apps)
  • Node.js LTS (18/20) — npm உடன்
  • Python 3.10+ — pip உடன்
  • Git
  • Visual Studio Code
  • Optional: Postman/Bruno
பின் பகுதி அமைப்பு (Backend Setup)
  • python -m venv .venv
  • Activate venv → packages install
  • pip install -r requirements.txt
  • API இயக்க:
    python -m uvicorn main:app --reload --port 8000
  • Optional .env keys:
    TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_SMS_FROM, TWILIO_WHATSAPP_FROM, RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET, RAZORPAY_WEBHOOK_SECRET
முன் பகுதி அமைப்பு (Frontend Setup)
  • npm install
  • npm run dev
  • Theme & settings localStorage‑ல் சேமிக்கப்படும்
  • UI: http://localhost:5173
நெட்வொர்க் & OS (Networking & OS)
  • Windows Firewall: 8000, 5173 inbound allow
  • API: http://localhost:8000/settings
  • UI: http://localhost:5173
துணை கருவிகள் (Optional Tools)
  • GitHub Desktop
  • nvs (Node Version Switcher)
  • Image tools (Paint/Photos) — logo upload
இந்தப் பக்கத்தை PDF ஆக print செய்யவும். Settings மாற்றியதும் மறுபடியும் print செய்யலாம்.
